# TradeMind AI

AI-powered NSE Stock Intelligence Platform.

## Features
- Real-time NSE Stock Data
- AI Multi-Agent Consensus (Technical, Fundamental, News)
- Smart Money Concepts (OB, FVG, Liquidity)
- Wyckoff & Elliott Wave Analysis
- ML-based Price Prediction (LSTM)
- Professional Trading Dashboard
- AI Chat Assistant

## Setup

### Backend
1. `cd backend`
2. `pip install -r requirements.txt`
3. `cp .env.example .env`
4. `uvicorn backend.app.main:app --reload`

### Android
1. Open in Android Studio
2. Build and run

### Docker
`docker-compose up --build`
