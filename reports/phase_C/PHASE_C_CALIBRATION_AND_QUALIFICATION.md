## 1. Probability Calibration Contract

- **Raw Probability**: $P_{\text{raw}}(\text{UP})$ generated by VotingClassifier ensemble (`predict_proba`).
- **Isotonic Calibration / Platt Scaling**: `CalibrationService.calibrate_isotonic(raw_prob, calibrator_model)`.
- **Domain Constraint**: Calibrated probability $P(\text{UP})$ is strictly bounded in $[0.0, 1.0]$.
- **Zero Fallback Protection**: A raw probability of `0.0` or unavailable model output evaluates to `calibrated_probability_up = 0.0` and `prediction = "UNAVAILABLE"`, which fails closed and is never converted to a 100% short trade.

## 2. Hard Signal Publication & Qualification Gates

`SignalQualityService.should_publish(horizon, model, calibrated_prob)` enforces statistical quality gates:
1. **Registered Metadata Guard**: `model` must not be `None`. Unregistered models unconditionally return `False`.
2. **Minimum Data Visibility**: `test_size >= 20`. Models evaluated on fewer than 20 test samples are rejected.
3. **Horizon AUC Thresholds**:
   - `SWING`: `model.roc_auc > 0.52`.
   - `LONG`: `model.roc_auc > 0.65`, `positives_test >= 5`, and `accuracy != 0.5`.
4. **Probability Threshold**: `calibrated_prob >= 0.52`.
