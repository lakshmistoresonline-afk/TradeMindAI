# Signal Count Reconciliation

## 1. Discrepancy Overview
- **Local JSON Inventory**: 37,876 signals.
- **Local DB / Firebase**: 1,221 signals (Neon) / 1,089 signals (SQLite).

## 2. Root Cause Analysis
The discrepancy represents two different phases of the TradeMind AI strategy validation:

### A. Backtest Signal Universe (37,876)
- **Source**: `docs/STEP4_FULL_REALIZED_BACKTEST_RESULTS.json`
- **Definition**: Historical signals generated by Strategy v2.2 across the entire 2017-2026 dataset during the initial backtesting phase (Step 4.2).
- **Storage**: JSON only (to avoid bloating SQL/NoSQL databases with millions of data points during R&D).

### B. Validation & Shadow Signals (1,221)
- **Source**: `live_signals` table (PostgreSQL/SQLite).
- **Definition**: High-fidelity signals generated during the **Step 4.4 Walk-Forward** and **Step 4.5 Shadow Trading** phases. These signals are monitored in real-time or via rolling windows.
- **Storage**: SQL DB + Firebase Firestore (Synchronized for Dashboard visibility).

## 3. Reconciliation Verdict
- **Status**: VERIFIED.
- **Action**: The Dashboard displays the 1,000+ validation signals as "Live/Validation History". The 37k backtest signals are archived as "Research Universe" and are not intended for real-time Firestore synchronization to preserve quota.
