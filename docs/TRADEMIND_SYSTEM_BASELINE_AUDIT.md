# TradeMind AI: System Baseline Audit

## 1. Architecture Overview
TradeMind AI is a multi-tier algorithmic trading platform operating in **LIVE_SHADOW** mode.

- **Authoritative Database**: Neon (Postgres)
- **Mirror / UI Layer**: Firestore
- **Intelligence**: Multi-tier (Market, Sector, Stock, Institutional, F&O)
- **Strategy**: V2.2 (Frozen)
- **Validation**: Quantitative (Walk-forward, Calibration)

## 2. Core Data Flows
- **Market Data -> Features**: Ingested via Yahoo/Groww providers into analytical engines.
- **AI/ML -> Signal**: Predictions generated by Random Forest models, uniquely identified.
- **Signal -> Outcome**: Forensic lifecycle auditing using 1m OHLC data.
- **Outcome -> Portfolio**: Virtual accounting with 0.20% friction.

## 3. Detected Technical Debt & Placeholders
- `regime_engine`: Uses mock data for live detection if index history is missing.
- `evidence_matrix`: Placeholder logic for context extraction.
- `sector_rotation`: Volume score is a hardcoded 0.5.
- `stock_intelligence`: Fundamental score and institutional pressure are placeholders.
- `fundamental_service`: Simple database retrieval, lacks deep growth/valuation analysis.
- `ShadowPortfolioEngine`: Drawdown calculation method inconsistent with reporting.

## 4. Signal Lifecycle State Machine
- **States**: CREATED, ACTIVE, TARGET_HIT, STOP_LOSS, TIMEOUT, EXPIRED, CANCELLED.
- **Immutability**: Terminal states are theoretically irreversible but enforcement is primarily in Python logic, not DB constraints.

## 5. Quantitative Validation Health
- **Brier Score**: Integrated.
- **LogLoss**: Integrated.
- **Walk-forward**: Chronological splits enforced.
- **Sample Size**: n=50 milestone reached.

## 6. Known Inconsistencies
- **Drawdown**: Discrepancy between MD report (-6.30%) and JSON (15.69%).
- **Historical Live Signals**: 143-record delta between Neon and Firestore isolated.

## 7. Security Status
- `REAL_TRADING`: FALSE (Enforced).
- `BROKER_ORDER_ENABLED`: FALSE (Enforced).
- Secrets: Hardened `.gitignore` active.

---
**Verdict**: The system is engineering-complete for shadow mode but requires forensic reconciliation of metrics and removal of intelligence placeholders before scaling.
