# VISUAL DESIGN GUIDELINES: "THE TERMINAL SYSTEM"

## 🎨 COLOR PALETTE
- **Background (Base)**: `#020617` (Slate 950)
- **Background (Elevated)**: `#0f172a` (Slate 900)
- **Border**: `#1e293b` (Slate 800)
- **Primary (Signal)**: `#10b981` (Emerald 500)
- **Warning (Conflict)**: `#fbbf24` (Amber 400)
- **Error (Risk)**: `#f43f5e` (Rose 500)

## ✍️ TYPOGRAPHY
- **User Interface**: `Inter` (Sans-serif)
- **Financial Data**: `JetBrains Mono` or `Roboto Mono`
- **Scale**:
  - `Decision Hub`: 32pt - 48pt
  - `Header`: 18pt
  - `Sub-header`: 12pt (All caps, 1px tracking)
  - `Body`: 14pt
  - `Caption`: 10pt

## 📦 COMPONENT ARCHITECTURE
1.  **THE ALPHA CARD**: Use for "Signals" and "Opportunities." Emerald border, subtle glow.
2.  **THE DATA CARD**: Flat design, Slate 900. No borders, only 1px separator lines between rows.
3.  **THE CONTEXT CARD**: Transparent background, outlined border. Use for "Learning Mentor" or "Why Not" explanations.

---

## ✨ MICRO-INTERACTIONS
- **Haptic Hover**: Subtle elevation and border-color shift on hover.
- **Pulse**: High-conviction BUY signals should have a very slow, subtle background pulse.
- **Count-up**: Animate score and price changes on hydrate.
