# INFORMATION ARCHITECTURE REVIEW

## 🧩 NAVIGATION TOPOLOGY
The current structure is **Flat and Broad**. This works for developers but is tiring for users.

### Current Structure:
- 18+ Root level items.
- No logical nesting.

### Proposed Structure (The "Hedge Fund" Taxonomy):

1.  **MARKET RADAR**
    - `Live Pulse` (Dashboard)
    - `Global Macro` (Calendar)
    - `Sector Map` (Treemap/Heatmap)
2.  **INTELLIGENCE HUB**
    - `Stock Forensic` (Analysis Hub)
    - `Alpha Scanner` (Opportunities/Rankings)
    - `Digital Twin` (Identity)
3.  **STRATEGY & EXECUTION**
    - `Paper Trading`
    - `Strategy Lab` (Builder)
    - `Trade Journal` (Mentorship)
4.  **TERMINAL SETTINGS**
    - `Account`
    - `Admin` (System Health)

---

## 🏛️ DATA DNA (SYMBOL LEVEL)
Every symbol should follow a standardized **"Depth of Research"** path:

1.  **DECISION** (BUY/SELL/HOLD + Risk/Reward)
2.  **REASONING** (Why? + Evidence)
3.  **POSTURE** (Technical Indicators + SMC)
4.  **HEALTH** (Fundamental Ratios + Moat)
5.  **CONTEXT** (Digital Twin + Peer Comparison)
6.  **HISTORY** (Backtest + Recommendation Audit)

---

## ⚡ IA IMPROVEMENTS (CRITICAL)
- **Universal Search (Ctrl+K)**: Ensure it doesn't just find symbols, but also navigates to pages (e.g., typing "Calendar" goes to the Calendar page).
- **Deep Linking**: Clicking a symbol in the "Treemap" should take the user directly to the "Analysis Hub," not just the generic Market page.
