# TradeMind AI - Step 4.1 Execution Semantics

## 1. Favorable Gap Entry Rule
A limit order is filled at the **actual executable Open price** if the market gaps favorably beyond the limit.
- **LONG**: If `Open < Intended Entry`, fill at `Open`.
- **SHORT**: If `Open > Intended Entry`, fill at `Open`.

## 2. Invalid Fill Protection (Rule B)
If a favorable gap opens at a price that is already beyond the protective stop level, the order is considered **INVALID** and is not established.
- **LONG Logic**: If `Open < Stop`, do NOT fill.
- **SHORT Logic**: If `Open > Stop`, do NOT fill.

**Reasoning**: A position cannot be established if its risk parameters are already breached at the moment of execution. This prevents "phantom" zero-profit trades and ensures high-fidelity backtest results.

## 3. Target/Stop Basis
Target and Stop levels are calculated relative to the **Intended Entry (Signal Price)**.
- These levels represent fixed price points based on the strategy's signal conviction.
- Execution at a favorable gap price improves the Risk-Reward ratio (smaller risk, larger potential reward) but does not shift the absolute price levels of the target or stop.

## 4. Execution State Machine
1. **SIGNAL**: Generated by ML model.
2. **WAITING_FOR_ENTRY**: Monitoring for fill condition.
3. **CANCELLED/EXPIRED**: If entry is not hit within evaluation window or if stop is hit before entry.
4. **ENTRY_FILLED**: State transitions to ACTIVE.
5. **ACTIVE**: Monitoring High/Low/Open for Target/Stop/Expiry.
6. **OUTCOME**: Realized profit/loss.
