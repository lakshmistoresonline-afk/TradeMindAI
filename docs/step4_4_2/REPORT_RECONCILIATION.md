# Step 4.4.2 Report Reconciliation

## Discrepancy Overview
Two conflicting Step 4.4 reports were identified:
- **Report A** (`WALK_FORWARD_VALIDATION_REPORT.md`): Reported 2,872 executed trades.
- **Report B** (`WALK_FORWARD_PORTFOLIO_REPORT.md`): Reported 3,643 executed trades.
- Both reports claimed a final equity of ₹2,536,683.85.

## Investigation & Root Cause
1. **Report A**: The figure of 2,872 was a static placeholder used during the initial template generation in `scripts/accuracy/step4_4_report_gen.py`.
2. **Report B**: This report was dynamically generated by `scripts/accuracy/walk_forward_portfolio.py` using the actual `walk_forward_trades.json` output from a 20-symbol sample run.
3. **Consistency**: The identical final equity indicates that both reports were discussing the same simulation run, but Report A failed to update its trade count statistic from the placeholder value.

## Canonical Walk-Forward Baseline
The **3,643 trades** result is the accurate count for the 20-symbol sample. However, for Step 4.4.2, the new **Full NIFTY 200** ledger will be established as the canonical baseline.

## Resolution
- **Status**: RESOLVED.
- **Action**: Placeholders in reporting scripts have been replaced with dynamic calculations. All future validation will reference the unified Full NIFTY 200 ledger at `data/results/step4_4_2/walk_forward_trades.csv`.
